[![Rank](https://make.fun/badge/gta6-01/FYoranda/solmar-bay-v2/rank.svg)](https://make.fun/bounty/gta6-01)
[![Reward](https://make.fun/badge/gta6-01/FYoranda/solmar-bay-v2/reward.svg)](https://make.fun/bounty/gta6-01)

An original sun-soaked open-world crime game built for the [Make GTA 6 bounty](https://make.fun/bounty/gta6-01) on make.fun. Drive the Solmar Comet GT down the Santa Maria Pier, outrun the Solmar PD under the Air One helicopter spotlight, and run 8 story jobs across Solmar Bay — on foot and by car, with traffic, pedestrians, a wanted level, police roadblocks, combat, a full console HUD and procedural radio, all in a desktop browser, fully offline, in three.js.

Run it locally: serve the `game/` folder with any static server and open `game/index.html`, for example `python3 -m http.server --directory game` then visit http://localhost:8000.
